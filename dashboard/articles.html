Indep. is the countable independent figure: a citing work that shares no author with the paper it cites, is settled by corroboration or a complete Google Scholar author list, and is not withheld for language. It is what the exhibit PDFs mark in yellow. Distinct collapses the duplicate versions Scholar shows of the same paper. Review is the count of rows still awaiting a decision, which is zero throughout this packet — the queue closed on 2026-11-04 — and is kept so a reader can check that no publication has open work. Not marked counts an English row classified independent yet not highlighted, which on this snapshot is only a second listing of a work counted once elsewhere. Non-Eng. holds every row the language screen flags, which is its own bucket since 2026-11-03 — the screen supersedes a row's other classifications, so those rows are not also counted as unsettled. On paper the venue and status columns are dropped so the remaining columns fit the sheet width; both appear here on screen and in in dashboard/data/citation-data.json.
