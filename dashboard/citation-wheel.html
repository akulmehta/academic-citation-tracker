Citation wheel

The numbered circles are the PI’s publications, coloured by research programme in the same shades as the co-citation network. Around them, one dot per counted independent citation, grouped into the tinted sector of the publication it cites; a sector’s width is that publication’s share of the whole, so the rim reads as a second version of the per-publication bars. The solid band outside the dots shows where each programme’s sectors lie. Most dots are grey. The blue ones are the papers that cite more than one of these publications, and each is drawn with a line to the others it cites — those crossing lines are where the anticoagulant work and the glycoscience work are shown to be read together.

Which node is which publication

Hovering a dot gives the citing paper’s title, byline and a link to it; a printed sheet carries the sector colours, the node numbers and the counts instead, since a printout has no hover. The dots are spread by a collision pass so that none covers another, and each is held inside its own sector, so a dot’s position answers “which paper does this cite” on paper exactly as it does on screen. The complete row-level list, with each citation’s row_uid and the exhibit page that carries it, is every citing work.
